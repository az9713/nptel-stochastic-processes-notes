# Course-note production workflow

This project follows the prior NPTEL and Stanford independent study editions.

1. Inventory the exact playlist; identify instructor, institution, course, and
   accessible official material. Preserve retrieval times and hashes.
2. Acquire caption tracks locally. Read each sequentially; map changes of topic
   to verified recording intervals. Record unavailable or partial material.
3. Check the mathematical notation against lecture frames. Keep separate text,
   visual, and audio coverage records. Never claim complete audiovisual review
   from captions or still-image sampling.
4. Develop specification, result dependencies, notation, architecture, and a
   section-level outline. Review the plan and obtain the skill's author approval.
5. Draft one pilot section at a time, directly in chapter HTML. Use the
   transcript-grounded-textbook passes and rigorous-explainer editorial rules.
   Approve the pilot and representative figures before scaling the pattern.
6. Execute each chapter's lab and figure generators; verify printed values,
   limiting cases, numerical convergence, and solution reasoning.
7. Obtain two independent full science-editor reviews per chapter. Bind reports
   to body/code/generator/figure digests. Apply bounded repairs and targeted
   verification; a changed argument requires another full review.
8. Run whole-book structure, assumptions, notation, references, continuity,
   exercises, prose, and reader-simulation passes. Rebuild at quiet writer
   boundaries. Rebuild from a source-free release copy as a reproducibility check.
9. Validate local links, timestamps, math rendering, responsive layout, solution
   controls, code copying, printing, offline operation, and privacy boundaries.
10. Deliver the local edition with honest coverage and review reports. Publish
    only if this project's user authorization explicitly includes publication.
